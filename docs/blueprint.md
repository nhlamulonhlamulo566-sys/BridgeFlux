# **App Name**: BridgeFlux

## Core Features:

- Live Tunnel Dashboard: A centralized UI to monitor active TCP tunnels, status, and bandwidth consumption in real-time.
- Dynamic Subdomain Provisioning: Automated system to assign temporary or reserved public URLs to your local TCP services.
- Smart Diagnostics Tool: An AI-powered diagnostic tool that uses connection logs and local network status to identify and suggest fixes for tunnel failures.
- Terminal Script Generator: Generate one-line bash or powershell commands to initialize the local agent quickly.
- Traffic Inspector: A live-stream view of individual request packets passing through the tunnel for debugging purposes.
- Access Control Whitelisting: Secure your tunnel by restricting incoming public traffic to specific CIDR IP ranges via the dashboard.

## Style Guidelines:

- Primary color: Electric Blue (#3D81F5), selected for a technical and scientific feel that resonates with network infrastructure.
- Background color: Deep Onyx (#0B0D11), a dark-scheme foundation with the same hue as the primary but heavily desaturated for high contrast.
- Accent color: Vibrant Azure (#3DCFF5), providing a bright analogous contrast to highlight action buttons and active status indicators.
- Font pairing: 'Space Grotesk' for a precise, techy look in headlines, and 'Inter' for clean, readable body text in dense log viewers.
- Monolinear icons using thin strokes to maintain a clean, high-tech aesthetic, with neon glow effects for active connection statuses.
- A compact, modular dashboard grid that maximizes visibility for multiple log streams and status widgets simultaneously.
- Subtle pulsing glows for active tunnels and sliding transitions between terminal output views.
